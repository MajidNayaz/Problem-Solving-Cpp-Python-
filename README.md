# C++ Interview Preparation Roadmap

## Goal

Build strong problem-solving skills and solid C++ fundamentals. Complete each session in C++ first.
Once the solution is correct, optionally reimplement it in Python to
reinforce the algorithm.

## Workflow for Each Session

  -----------------------------------------------------------------------
  Time                       Activity
  -------------------------- --------------------------------------------
  **10 min**                 Review the concept and relevant
                             STL/functions.

  **40 min**                 Solve 2--3 challenges in **C++** without
                             looking at solutions.

  **10 min**                 Test edge cases, analyze time and space
                             complexity, and refactor.

  **Optional**               Reimplement one completed challenge in
                             **Python** to reinforce the algorithm.
  -----------------------------------------------------------------------

------------------------------------------------------------------------

## General Rules

-   Think through the algorithm before coding.
-   Test edge cases (empty input, one element, large input).
-   State the time and space complexity after every solution.
-   Prefer clean, readable code over clever tricks.
-   If stuck for more than 30 minutes, study the solution, close it, and
    implement it again from memory.
